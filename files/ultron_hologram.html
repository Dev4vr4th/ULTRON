ULTRON CORE

This needs webcam access to track your hand in the browser (nothing is uploaded — MediaPipe runs locally), and mic access if you want to talk to it (speech recognition also runs in-browser). It polls a local bridge server on localhost:8765 so a pinch, spread, or voice command can start or stop ultron_runtime.py. Run python gesture_bridge.py first if you want that part to work — the orb, hand tracking, and voice UI all work without it too, just without the ability to actually launch anything.

gesture_bridge.py prints a bridge token when it starts. Paste it below so this page can authenticate — without it, pinch/spread/voice reach the bridge but get rejected (403).
